编写代码不仅仅是写代码。我们已经手动验证代码能否运行，也使用说明文件确保它遵循标准。接下来还要考虑测试、lint 以及持续集成（CI）的其他环节。

**智能体技能**适合处理这类任务！技能可以帮助 Copilot 正确执行这些操作。

本课将学习：

- 探索现有的 `quality-checks` 技能。
- 自定义其结果格式。
- 重新加载并运行该技能。

## 场景

Tailspin Toys 使用 `quality-checks` 技能运行单元测试、lint 和类型检查。团队希望改进报告，让结果更易于阅读。

## 说明、脚本和资源

智能体技能将可复用的任务说明、可执行脚本和辅助资源打包起来，由智能体按需加载。技能的核心是一个以技能名称命名的文件夹，其中包含 Markdown 文件 `SKILL.md`。该 Markdown 文件通过 frontmatter 中的名称和描述定义技能，并说明其用途和调用时机。技能文件夹还可以包含脚本和其他资源子目录。

> [!NOTE]
> 技能不一定需要包含其他文件或文件夹。Tailspin Toys 的 `quality-checks` 技能只包含 `SKILL.md`，因为它使用项目已有的命令。

技能可以放在项目的 `.github/skills` 文件夹中，作为团队共享和复用的存储库资源；也可以放在用户技能目录 `~/.copilot/skills` 中。

## 探索技能

先查看 Tailspin Toys 团队创建的 `quality-checks` 技能，了解如何运行单元测试、lint 和类型检查。

1. 返回 Codespace。在 Codespaces 编辑器中打开 `.github/skills/quality-checks/SKILL.md`。
2. 阅读顶部的 `name` 和 `description`。描述帮助 Copilot 判断何时调用技能。
3. 阅读说明，了解它如何引导 Copilot 执行测试和 lint。
4. 注意目前技能中还没有 **Results output formatting** 部分。

## 修改技能前先运行一次

技能可以通过 Copilot CLI 直接调用，也可以使用自然语言调用。先请 Copilot 运行技能中的三项检查。

1. 返回 Interactive 模式下的筛选对话。
2. 使用以下提示：

   ```plaintext
   Run the quality-checks skill for unit tests, lint, and type checks.
   ```

3. 查看最后生成的报告。

## 自定义报告

现在改进报告，让它说明运行了什么、是否成功，以及工具实际报告的内容。请更新技能，生成这样的报告。

1. 返回 `.github/skills/quality-checks/SKILL.md`。
2. 在文件末尾添加以下部分：

   ```markdown
   ## Results output formatting

   Upon completion, report each command that ran and whether it passed, failed, or was blocked. Include test counts, durations, errors, warnings, and other metrics only when the tool reports them. Identify the next action for any failure or blocker, and never describe a skipped or incomplete check as passed.
   ```

3. 文件会自动保存。

## 运行更新后的技能

更改完成后，检查运行效果。Copilot CLI 可以在不重启对话的情况下重新加载已编辑的技能。

1. 输入：

   ```plaintext
   /skills reload
   ```

2. 使用与之前完全相同的提示：

   ```plaintext
   Run the quality-checks skill for unit tests, lint, and type checks.
   ```

3. 查看最后生成的报告，并与第一次运行的结果对比。

## 总结与后续步骤

你已自定义并使用现有智能体技能。本课中，你：

- 探索了用于单元测试、lint 和类型检查的 `quality-checks` 技能。
- 自定义了结果报告格式。
- 重新加载并运行了技能。

这项更改将与筛选功能一起放入功能 PR。接下来，[通过 Playwright MCP 服务器][next-lesson]让 Copilot 直接与网站交互。
